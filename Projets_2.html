// SAÉ 1.05 — Développement
SAÉ 1.05 — DÉVELOPPEMENT
Outil d'Analyse & Nettoyage de Disque
Python PowerShell PyQt5 JSON

Ce projet, réalisé dans le cadre de la SAÉ 1.05 du B.U.T. R&T, avait pour objectif de concevoir un outil logiciel complet capable d'analyser l'espace disque d'un serveur réseau, d'identifier les fichiers les plus volumineux, et de permettre leur suppression de manière sécurisée via une interface graphique intuitive. La contrainte principale était d'assurer une communication fiable entre un orchestrateur PowerShell, un moteur d'analyse Python et une interface PyQt5 — trois composants technologiquement distincts devant fonctionner comme un seul système cohérent. Ce projet m'a confronté à de vrais défis d'ingénierie logicielle : gestion des chemins réseau UNC, précision numérique sur les fichiers de petite taille, et conception d'une IHM qui soit à la fois fonctionnelle et agréable à utiliser.

Architecture du projet
  • sae.ps1 — Orchestrateur PowerShell chargé de préparer l'environnement d'exécution, vérifier les dépendances Python, et monter les volumes réseau distants via New-PSDrive avant de lancer le pipeline d'analyse
  • analyse.py — Moteur d'analyse Python qui parcourt récursivement l'arborescence de fichiers (os.walk), calcule la taille de chaque entrée, trie les résultats par ordre décroissant, puis exporte les données au format JSON structuré
  • main_gui.py — Interface graphique PyQt5 qui charge le JSON produit par le moteur, affiche une visualisation en camembert de l'occupation disque, propose un tableau interactif des fichiers, et permet la suppression après confirmation explicite de l'utilisateur
Défis techniques résolus
  • Gestion des chemins UNC (\\serveur\partage) — montage automatisé via New-PSDrive pour rendre les partages réseau accessibles comme des lecteurs locaux depuis Python
  • Précision numérique — implémentation de la division flottante et du round() pour afficher correctement les fichiers de moins d'1 Mo sans perte de précision
  • Communication inter-processus — passage de données entre PowerShell et Python via fichier JSON intermédiaire, avec gestion des erreurs et des cas limites
  • Suppression sécurisée — implémentation d'une double confirmation utilisateur avant toute suppression irréversible depuis l'interface Qt
Objectifs pédagogiques atteints
  • AC11.02 — Mise en œuvre d'algorithmes complexes : récursivité, tri, structures de données imbriquées
  • Maîtrise du scripting système avancé et de l'interopérabilité entre environnements d'exécution distincts
  • Conception d'une Interface Homme-Machine (IHM) orientée utilisateur avec le framework Qt
Compétences acquises
  • Programmation Python avancée — os.walk, json.dump/load, sorted() avec key, gestion des exceptions
  • Scripting PowerShell — New-PSDrive, Start-Process, gestion des codes de retour et des erreurs
  • Développement d'interfaces graphiques complexes avec PyQt5 (QTableWidget, QChartView)
  • Architecture logicielle modulaire et principe de séparation des responsabilités (SRP)
🇬🇧 English Summary

This project involved designing a modular disk analysis and cleanup tool for network servers. Built with three interconnected components — a PowerShell orchestrator, a Python analysis engine, and a PyQt5 graphical interface — it identifies large files, exports results as JSON, and allows secure deletion through a confirmation-based UI. Key challenges included handling UNC network paths, ensuring floating-point precision for small file sizes, and managing inter-process communication between PowerShell and Python.

// SAÉ 1.02 — Réseaux
SAÉ 1.02 — RÉSEAUX
Architecture Réseau d'Entreprise
EVE-NG Cisco IOS VLAN / VTP DHCP Linux

La SAÉ 1.02 m'a permis de concevoir et déployer from scratch un réseau local d'entreprise complet dans un environnement de virtualisation réseau professionnel — EVE-NG. L'objectif était de simuler l'infrastructure d'une PME avec plusieurs départements distincts, chacun isolé dans son propre VLAN, tout en maintenant une communication inter-segments contrôlée et un service DHCP centralisé. Ce projet représente ma première confrontation avec la complexité réelle d'un réseau d'entreprise : comprendre pourquoi on segmente, comment propager les VLANs efficacement sans les configurer manuellement sur chaque switch, et comment un serveur Linux peut distribuer des adresses IP différentes selon le VLAN d'origine de la requête. C'est également ma première expérience avec la CLI Cisco IOS dans un contexte de projet structuré avec cahier des charges.

Implémentation technique
  • Segmentation réseau en VLANs fonctionnels — Direction (VLAN 10), Employés (VLAN 20), Wi-Fi Invités (VLAN 30) — chaque segment isolé par défaut du reste du réseau
  • Propagation automatique des VLANs entre les switches via le protocole VTP (VLAN Trunking Protocol) — configuration du serveur VTP et des clients pour synchronisation centralisée
  • Déploiement d'un serveur DHCP sous Linux Debian avec gestion des scopes par VLAN — configuration du DHCP relay sur les interfaces des routeurs pour acheminer les requêtes BOOTP vers le serveur central
  • Routage inter-VLAN implémenté via Router-on-a-Stick sur sous-interfaces 802.1Q — permet la communication contrôlée entre segments tout en maintenant la segmentation
  • Validation de bout en bout : tests de connectivité ping et traceroute entre toutes les machines virtuelles, vérification des tables de routage et des attributions DHCP
Environnement utilisé
  • EVE-NG — plateforme de virtualisation réseau permettant de simuler du matériel Cisco réel sans équipement physique
  • Routeurs et switches Cisco IOS — configuration via CLI exclusivement, comme en environnement professionnel
  • Serveur Linux Debian 12 — installation et configuration du daemon ISC DHCP avec fichier dhcpd.conf multi-scope
  • VPC (Virtual PC Simulator) — simulation des postes clients pour valider la connectivité et les attributions d'adresses
Objectifs pédagogiques atteints
  • AC11.03 — Configurer les fonctions de base du réseau local : VLANs, trunking, commutation de couche 2
  • Compréhension approfondie du modèle OSI appliqué à un cas concret de segmentation réseau
  • Maîtrise des commandes CLI Cisco pour la configuration, le diagnostic et la vérification d'état
Compétences acquises
  • Configuration CLI Cisco — VLAN, VTP, trunk/access ports, sous-interfaces 802.1Q, routes statiques
  • Administration du daemon DHCP Linux en environnement multi-VLAN avec DHCP relay
  • Diagnostic réseau avancé — show vlan brief, show ip route, show interface trunk, debug ip dhcp
  • Méthodologie de résolution de problèmes réseau : isolation de la couche défaillante, lecture des logs système
🇬🇧 English Summary

This project involved designing and deploying a complete enterprise LAN from scratch using EVE-NG as the network virtualization platform. The infrastructure includes multi-VLAN segmentation (Management, Employees, Guest Wi-Fi), automatic VLAN propagation via VTP, a centralized Linux DHCP server with per-VLAN scope management, and inter-VLAN routing using Cisco Router-on-a-Stick. All configuration was performed exclusively through the Cisco IOS CLI, replicating real-world enterprise conditions.

// Labs personnels — Cybersécurité
LABS PERSONNELS — CYBERSÉCURITÉ
Labs Réseaux & Cybersécurité
Kali Linux TryHackMe Packet Tracer ACL Cisco VirtualBox

En dehors des cours, je consacre du temps à des labs pratiques en autonomie pour aller au-delà du programme académique et développer une vraie culture cybersécurité. Ces entraînements couvrent deux axes complémentaires : d'un côté la consolidation des compétences réseau défensives (ACL, topologies complexes, filtrage de trafic), de l'autre une initiation progressive à la cybersécurité offensive via TryHackMe et ma VM Kali Linux. Cette démarche autonome reflète une conviction simple : un étudiant sérieux en cybersécurité ne peut pas se contenter du programme de cours — il faut pratiquer sur des cas concrets, se confronter à de vrais défis techniques, et comprendre comment les attaquants pensent pour mieux savoir se défendre.

Labs réseau défensifs
  • Configuration d'ACL standard et étendues sur routeurs Cisco — filtrage granulaire du trafic IP par adresse source, destination, protocole et port, avec vérification des hit-counts pour valider les règles
  • Conception de topologies multi-routeurs avec routes statiques et introduction aux protocoles de routage dynamique (OSPF)
  • Configuration NAT statique et dynamique — translation d'adresses pour la sortie vers Internet depuis un réseau privé
  • Simulation d'infrastructures réseau complètes sous Cisco Packet Tracer avec validation de bout en bout
Cybersécurité offensive (initiation)
  • Pratique sur TryHackMe — parcours "Pre-Security" et modules d'introduction à la cybersécurité offensive et défensive
  • VM Kali Linux dédiée sous VirtualBox — environnement isolé pour expérimenter les outils de pentesting sans risque pour le réseau principal
  • Découverte des outils fondamentaux : Nmap (scan réseau), Nikto (scan web), bases de l'exploitation de vulnérabilités connues
  • Compréhension des techniques d'attaque courantes pour mieux anticiper les défenses à mettre en place
Administration système Linux
  • Gestion des utilisateurs, groupes et permissions sous Linux Debian — chmod, chown, sudoers
  • Administration des services système via systemctl — activation au démarrage, surveillance de l'état des processus
  • Configuration des règles de pare-feu iptables pour filtrer le trafic entrant et sortant
  • Analyse des logs système pour identifier des comportements anormaux ou des tentatives d'intrusion
Compétences développées
  • Maîtrise des ACL Cisco standard et étendues pour la sécurisation périmétrique des réseaux
  • Administration système Linux autonome dans un environnement virtualisé
  • Initiation à la pensée offensive — comprendre les vecteurs d'attaque pour mieux défendre
  • Culture cybersécurité Blue Team : veille, analyse de logs, défense en profondeur
🇬🇧 English Summary

Beyond academic coursework, I independently practice both defensive and offensive cybersecurity. On the defensive side, I work on Cisco ACL configurations, multi-router topologies, and NAT setups using Packet Tracer. On the offensive side, I actively train on TryHackMe and run a dedicated Kali Linux VM under VirtualBox to experiment with penetration testing tools such as Nmap and Nikto. This self-driven approach reflects my commitment to understanding how attackers think in order to build stronger, more resilient defenses.

// Projet personnel — Modélisation 3D
PROJET PERSO — FUSION 360
Mask Algorhack — Toupie Beyblade Burst Custom
Fusion 360 Modélisation 3D Polycarbonate TPU Impression 3D

Mask Algorhack est un projet de conception entièrement original d'une toupie Beyblade Burst custom, modélisée de A à Z sous Autodesk Fusion 360. Le nom est une création personnelle : "Algor" vient d'algorithme — la précision du calcul, la logique implacable — et "Hack" fait référence à la mécanique centrale de la toupie, le spin steal, qui consiste littéralement à pirater le momentum rotatif de l'adversaire. Ce projet est né d'une passion personnelle pour l'univers Beyblade Burst et d'une volonté de transformer ce hobby en apprentissage concret de la CAO. Chaque mesure a été prise sur des pièces réelles de référence (BlastKatana) pour garantir la compatibilité avec le système Burst officiel. L'objectif final est l'impression physique des pièces au FabLab Technistub de Mulhouse (polycarbonate + TPU), puis le test en conditions réelles contre de vraies toupies.

Concept & mécanique
  • Type : Stamina / Spin Steal — la toupie ne cherche pas à éjecter l'adversaire mais à absorber progressivement son énergie cinétique jusqu'à l'arrêt complet
  • Double rotation native (Dual Spin) — compatible aussi bien en rotation horaire qu'anti-horaire, permettant le spin steal dans les deux configurations possibles en tournoi
  • Layer en polygone 9 côtés — diamètre extérieur 50mm, 2 rangées de 9 lames chacune soit 27 points de contact total (27 = chiffre personnel symbolique)
  • Armure caoutchouc TPU enveloppant chaque lame — augmente la surface de friction au contact et rend la toupie quasi-inburstable grâce à l'absorption des chocs
  • Driver Bearing Drift — pointe à roulement à billes permettant une rotation libre avec déviation progressive vers le centre de l'arène, maximisant le LAD (Life After Death)
Données techniques & mesures
  • Diamètre extérieur du layer : 50mm (référence BlastKatana)
  • Trou central : 14.6mm — compatibilité standard système Burst
  • Ring intérieur (zone burst teeth) : 34.5mm de diamètre
  • Hauteur totale du layer : ~9.056mm
  • Dents de burst : ~1.3mm d'épaisseur, 5.9mm de hauteur, 5 dents par face — conçues asymétriques pour résister au déburst dans les deux sens de rotation
  • Congés (arrondis) appliqués sur les arêtes extérieures pour éviter les cassures à l'impression et améliorer le transfert d'énergie au contact
Matériaux & fabrication
  • Layer principal : Polycarbonate (PC) — matériau haute résistance aux chocs, rigidité optimale pour maximiser le moment d'inertie et la durabilité en combat
  • Armure caoutchouc : TPU (Thermoplastic Polyurethane) — flexibilité contrôlée, coefficient de friction élevé pour le spin steal, absorption des vibrations
  • Lieu d'impression prévu : FabLab Technistub Mulhouse (130 Rue de la Mer Rouge) — équipé d'imprimantes compatibles PC et TPU
  • Alternative envisagée pour pièces métalliques : JLC3DP (usinage CNC ou impression métal) si des composants en aluminium s'avèrent nécessaires
Compétences développées
  • Maîtrise des outils de modélisation paramétrique Fusion 360 : esquisses contraintes, extrusions, révolutions, congés, perçages
  • Lecture et prise de mesures sur pièces mécaniques réelles pour assurer la compatibilité dimensionnelle
  • Compréhension des propriétés mécaniques des matériaux d'impression 3D (PC vs TPU) et de leurs implications sur le design
  • Application des lois physiques (conservation du moment angulaire, moment d'inertie, friction) dans un contexte de design produit
Visuels du projet
Layer principal — vue isométrique complète
Ring extérieur TPU — pièce de spin steal
🇬🇧 English Summary

Mask Algorhack is an original custom Beyblade Burst top designed and modeled from scratch in Autodesk Fusion 360. The name combines "Algor" (algorithm) and "Hack," referencing its core mechanic: spin stealing — literally hacking the opponent's rotational energy. The layer features a 9-sided polygon at 50mm diameter with 27 blade contact points, a dual-spin system, a TPU rubber armor for maximum friction and burst resistance, and a Bearing Drift driver for optimal stamina and LAD. All dimensions were taken from real Burst reference parts. The final goal is 3D printing in polycarbonate (layer) and TPU (rubber armor) at a local FabLab for real-world testing.

// Projet personnel — BIM & Architecture
PROJET PERSO — REVIT 2026
Modélisation BIM — Maison Plain-Pied
Autodesk Revit 2026 BIM Modélisation 3D Architecture Plans 2D

Ce projet marque mon entrée dans l'univers du BIM (Building Information Modeling) via Autodesk Revit 2026, obtenu gratuitement via la licence étudiante Autodesk Education. L'objectif était de partir d'un plan architectural réel d'une maison plain-pied et de le modéliser intégralement dans Revit — des murs porteurs jusqu'aux menuiseries, en passant par les cloisons, les portes et les fenêtres — pour obtenir à la fois un plan 2D coté professionnel et une vue 3D isométrique automatiquement générée par le logiciel. Ce premier projet représente bien plus qu'un simple exercice technique : il s'inscrit dans une vision long terme. Avec mon profil B.U.T. Réseaux & Télécommunications, maîtriser Revit me permet d'envisager une spécialisation rare et très recherchée — la modélisation des infrastructures CFO/CFA dans les bâtiments intelligents (chemins de câbles réseau, armoires de brassage, points d'accès Wi-Fi, IoT). Ce combo Réseaux/Cybersécurité + BIM est aujourd'hui quasi inexistant sur le marché.

Ce qui a été modélisé
  • Structure complète d'une maison plain-pied — murs extérieurs en parpaing, cloisons intérieures, isolation périmétrique représentée
  • Pièces modélisées : 3 chambres (9m², 9.33m², 9.06m²), dressing (2.7m²), salle d'eau (5.15m²), WC (1.15m²), dégagement (2.62m²), séjour (37.23m²), salon, cuisine, cellier (3.72m²), garage (14.8m²)
  • Menuiseries : portes intérieures avec représentation symbolique de l'ouverture (arc de cercle), fenêtres positionnées selon le plan de référence
  • Génération automatique du plan 2D coté depuis le modèle 3D — avec dimensions précises en millimètres pour chaque pièce et chaque baie
  • Vue 3D isométrique générée par Revit en "Aperçu technique" — permet de visualiser l'ensemble de la structure en coupe ouverte
Méthodologie & apprentissage
  • Apprentissage par la pratique directe — suivi d'une formation vidéo complète en conditions réelles, modélisation au fil de l'apprentissage sans phase théorique préalable
  • Prise en main de l'interface Revit : navigateur de projet (raccourci PP), vues par niveau, passage entre vue 2D et vue 3D, contrôle de l'échelle d'affichage
  • Compréhension des familles Revit — différencier les murs de base, les murs de refend, les familles de portes et fenêtres paramétriques
  • Gestion des niveaux (Niveau 0, toiture) et des vues de coupe pour naviguer dans le modèle de manière professionnelle
Vision long terme — BIM + Réseaux
  • Objectif : maîtriser la modélisation MEP (Mécanique, Électricité, Plomberie) dans Revit pour y intégrer les infrastructures réseau et télécom des bâtiments intelligents
  • Application directe du profil R&T : modéliser les chemins de câbles, les armoires de brassage, les points d'accès Wi-Fi et les équipements IoT dans une maquette BIM
  • Projet entrepreneurial à horizon 2028-2030 : créer une structure spécialisée dans la modélisation CFO/CFA pour les Smart Buildings, en collaboration avec un associé d'Oman (pays pionnier dans ce domaine)
  • Ce combo BIM + Réseaux/Cybersécurité est aujourd'hui quasi inexistant en France — c'est une niche stratégique avec une demande croissante liée à l'essor des bâtiments connectés
Compétences acquises
  • Prise en main complète d'Autodesk Revit 2026 — interface, navigateur de projet, gestion des vues et des niveaux
  • Modélisation architecturale 2D/3D à partir d'un plan réel — murs, menuiseries, cloisons, annotations
  • Génération de plans techniques cotés et de rendus 3D depuis un unique modèle BIM
  • Compréhension du paradigme BIM — modèle unique source de vérité pour toutes les disciplines du bâtiment
Visuels du projet
Plan 2D coté — vue Niveau 0
Vue 3D isométrique — aperçu technique
🇬🇧 English Summary

This project is my first hands-on experience with Autodesk Revit 2026, completed using a free Autodesk Education student license. Starting from a real architectural floor plan of a single-story house, I modeled the full structure — load-bearing walls, partitions, doors, windows — generating both a dimensioned 2D plan and an isometric 3D view automatically. Beyond the technical exercise, this project is part of a long-term vision: combining my B.U.T. Networks & Telecommunications background with BIM expertise to specialize in smart building infrastructure modeling (network cable trays, patch panels, Wi-Fi access points, IoT devices). This Networking/Cybersecurity + BIM combination is extremely rare on the French market and positions me for a high-demand niche in the growing Smart Building industry.
